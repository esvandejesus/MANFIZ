# Procedencia y publicación

El manuscrito y los archivos MATLAB suministrados identifican como autor a
Esvan-Jesús Pérez-Pérez. Esta distribución contiene su conversión a Python y
las correcciones matemáticas y verificaciones descritas en la documentación.

El paquete se preparó para revisión y futura carga a un repositorio. La licencia
de publicación queda por definir por el autor; este paquete no asigna una licencia
de código abierto ni inventa una URL de repositorio o un DOI. `CITATION.cff`
contiene únicamente los datos de autoría y versión disponibles.

Las dependencias NumPy, SciPy, Matplotlib y scikit-learn se instalan por separado.
Los datos de `tests/fixtures` provienen de los archivos aportados por el autor y
se usan exclusivamente como referencias numéricas de prueba.
